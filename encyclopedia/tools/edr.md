# EDR / XDR (엔드포인트 탐지·대응)

## Definition (정의)

EDR/XDR (엔드포인트 탐지·대응) records host activity and supports authorized investigation and response; XDR may correlate other controls.

## Why it matters

A deployed agent is useful only when it reports on the relevant host and retains the needed events.

## How to do it / what to check

Measure coverage by asset, validate process and file telemetry, test host isolation and rollback authority, and collect evidence before destructive action.
