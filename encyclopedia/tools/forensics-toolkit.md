# Forensics and live-response tools (포렌식 도구)

## Definition (정의)

Forensics and live-response tools (포렌식 도구) capture and analyze system, storage, memory and log evidence.

## Why it matters

A collection tool can alter a live system or leak personal data if it is used without a plan.

## How to do it / what to check

Choose a read-only method where possible, record version and command, hash outputs, restrict access, verify completeness and preserve original evidence.
